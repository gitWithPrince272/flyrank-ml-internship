FlyRank ML Internship Research Paper

Question

How can machine learning models identify and prioritize website pages that have opportunities for SEO improvement?

Data

The analysis uses the FlyRank anonymized content dataset containing SEO signals such as impressions, CTR, average position and engagement metrics.

Methodology

  • Data preparation and feature selection
  • Baseline ranking approach
  • Decision Tree Regression model
  • Validation and leakage checks

Results

Decision Tree model evaluation:
MAE: 13.9047
R² Score: 0.4541

Limitations

The model is a decision-support baseline and requires human review before actions.

Recommendations

  • Review pages with high impressions and low CTR
  • Improve content quality and search intent alignment
  • Monitor ranking changes
