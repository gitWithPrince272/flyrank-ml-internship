# 5 Minute Demo Outline

## 1. Problem (30 seconds)
Explain the SEO page prioritization problem and why identifying improvement opportunities is useful.

## 2. Dataset (1 minute)
The project uses FlyRank anonymized content data containing SEO signals:
- impressions
- CTR
- average position
- engagement metrics
- content features

## 3. Methodology (1 minute)
Workflow:
- Data preparation and feature selection
- Baseline ranking approach
- Decision Tree Regression model
- Validation and leakage checks

## 4. Results (1 minute)
Model performance:
- MAE: 13.9047
- R² Score: 0.4541

The model works as a decision-support baseline and requires human review.

## 5. Recommendation (30 seconds)
Prioritize pages with high impressions and low CTR, improve content alignment, and monitor ranking changes.
